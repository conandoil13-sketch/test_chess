# CB-120 · Claude Test

`chessworld_test`와 같은 흐름(월드 탐색 → 캐릭터 선택 → 목적지 선택 → 이동관리국 심사 → 승인 시 이동 / 거절 시 잔류)을 **시각 완성도 위주로 새로 만든 실험 버전**입니다. 기존 `chessworld_test`는 수정하지 않았습니다.

## 실행

```bash
cd claude_test
python3 -m http.server 8123
```

브라우저에서 http://localhost:8123 을 엽니다. (ES 모듈이라 파일을 직접 여는 방식으로는 동작하지 않습니다.)

## 이 버전에서 달라진 점

| 영역 | 내용 |
| --- | --- |
| 월드 | 20×20 전체를 한 장의 도트 텍스처(1280×1280)로 생성하고 2배 확대합니다. 지형은 칸을 넘어 이어지고(강·호수·숲·경작지), 모든 칸은 고딕 성벽(뾰족 흉벽, 버팀벽, 빛나는 첨두 총안)과 원뿔 첨탑 망루, 첨두 아치 성문으로 나뉩니다. 사이버 구역 성벽에는 네온 띠가 있습니다. |
| 건물 | 고딕과 사이버펑크를 섞은 오블리크 시점 건물을 코드로 그립니다. 회청색 돌 벽과 뾰족 박공, 첨두창(따뜻한 빛·하늘빛·분홍빛), 가파른 첨탑과 피너클이 기본이고, 도시 구역에는 네온 간판, 사이버 구역에는 첨두 창 띠·톱니 지붕·안테나 첨탑을 가진 어두운 빌딩이 섞입니다. 그림자 패스와 깊이 정렬이 있습니다. |
| 빛 | 별도 캔버스에서 창문, 네온, 횃불, 비컨이 깜빡이고 물이 반짝입니다. 중심 항성이 없는 설정에 맞춰 낮·밤 없이 일정한 어두운 조도를 씁니다. |
| 우주 | 행성 바깥은 도트 우주입니다. 3겹 패럴랙스 별(반짝임), 성운·은하수 띠, 화면 곳곳(위·아래·좌우)에 흩어져 천천히 자전하며 떠가는 다른 행성 10개(고리 가스 행성 2·청록/주황/연둣빛 가스 행성·얼음·용암·암석, 시안), 별똥별, 궤도 물체가 있습니다. 설정상 중심 항성과 달이 없으므로 태양·달처럼 보이는 천체는 넣지 않았습니다. |
| 승급소 (시안) | 맨 위 줄·맨 아래 줄 20칸마다 발착장(팔각 석조 단, 네 방위 작은 첨탑, 원뿔 지붕 관제탑)과 고딕 첨탑 모양 로켓(바늘 기수, 장미창, 버팀벽 날개, 하늘빛 분사)이 있고, 행성 밖에 떠 있는 승급소 칸(위: 백 승급소, 아래: 흑 승급소)으로 우주선이 수시로 이륙·비행·도킹합니다. 승급소는 사용자 참고 이미지를 따라 구름 위 절벽 섬에 세운 고딕 첨탑(5단, 빛나는 첨두창, 작은 첨탑들)과 원형 광장·빛기둥 분수, 사이프러스, 난간, 착륙판이 달린 도킹 탑 2개로 구성했고, 섬 옆면은 빛나는 아치창이 박힌 석벽과 바위입니다. 우주선은 도킹 탑 꼭대기에 내려앉습니다. **시각 연출만 있고 승급 기능은 없습니다.** 위치(양 끝 가로줄), 우주선 이동 방식, 백·흑 구분은 시안이며, 세계관 문서의 ‘낭떠러지에 인접한 탑’ 설정과는 형태가 다릅니다. |
| 시점 | 정면을 유지하며 위쪽이 멀어지는 3D 기울기(42°)이고, 맵 가장자리에는 낭떠러지 단면이 있습니다. 드래그, WASD, 휠, Q/E·핀치 확대, F(내 위치), 미니맵 클릭을 지원합니다. |
| 체시언 마커 | 상반신(유기체)과 팔각 기계 하반신·다리를 가진 20×30 도트 스프라이트이며 계급별 머리가 다릅니다. **최종 캐릭터 디자인이 아닙니다.** |
| HUD | 돌판 같은 어두운 패널에 모서리 장식선, 위쪽 가운데 뾰족 아치 장식과 작은 네온 마름모, 위 가장자리 네온 한 줄을 넣었습니다. 초상 프레임은 첨두창 모양이고 버튼·칩은 모서리를 깎은 돌판입니다. ‘관측 시작’·‘이동관리국에 제출’·‘검사 실행’ 같은 결정 버튼은 노란 버튼 대신 양 끝이 뾰족한 스테인드글라스 인장입니다. 옅은 납선 마름모가 든 보랏빛 유리를 돌 색 테두리가 감싸고, 9초에 한 번 은은한 빛이 유리를 천천히 지나갑니다. HUD라서 글로우는 최소로만 씁니다. |
| 로딩 화면 | 고딕 관측 성당을 도트로 그린 장면입니다(`js/nave.js`). 리브 볼트와 다발 기둥, 신도석, 붉은 통로 깔개, 제단과 촛불, 양옆 스테인드글라스 첨두창과 작은 원창, 가운데 큰 창(창살 4개 + 장미창)이 있습니다. 장미창 가운데 투명한 원창 너머로 정육면체 행성 CB-120이 약 30° 기운 축으로 돌며, 여섯 면에 실제 월드 지표가 감겨 있습니다(체스판 칸, 성벽 같은 모서리). 행성의 어느 면이 각 창을 향하느냐에 따라 그 창의 유리 밝기와 색이 바뀌고, 창에서 내려오는 빛줄기와 바닥·신도석에 비치는 창살 무늬도 함께 바뀝니다. 빛줄기를 지나는 먼지만 반짝이고, 앞쪽 큰 촛대는 pixelfx 촛불입니다. 벽돌 줄눈을 따라 시안·마젠타·보랏빛 네온 여러 줄기가 천천히 위에서 아래로 내려옵니다. 세로 줄눈을 한 단 내려간 뒤 가로 줄눈에서 반 장(가끔 몇 장) 옆으로 옮겨 다시 내려가는, 사다리 타기 같은 경로입니다. 기둥이나 창에 가리지 않는 줄눈에서만 생겨납니다. 진행 막대는 석조 띠 안의 첨두 슬릿이 차오르는 방식입니다. 좌상단 타이틀에는 체스판 스테인드글라스 문장과 금빛 각인 제목을 썼습니다. |
| 신청 흐름 | 목적지를 선택하면 바로 넘어가지 않고 ‘이동 신청서’ 확인 창이 뜹니다(Enter 제출 / Esc 다시 고르기). |
| 전환 | 체스판 타일이 대각선 물결로 덮였다가 걷힙니다. |
| 이동관리국 | 고딕 석조 홀 배경을 도트로 그립니다(로딩 화면과 같은 `js/nave.js`). 리브 아치, 벽기둥, 몰딩 띠, 블라인드 아케이드, 체스판 대리석 바닥, 창턱의 봉헌 촛불, pixelfx 횃불이 있습니다. 횃불 불꽃은 평소 주황이고 승인이면 초록, 거절이면 빨강으로 바뀝니다. 첨두창 4개와 작은 장미창 2개는 평소엔 별이 보이는 바깥 하늘인 척하다가, 검사 중엔 하늘빛 띠가 훑고 지나가고, 승인이면 초록, 거절이면 깜빡이는 빨강 스테인드글라스로 켜집니다. 켜진 창에서는 같은 색 빛줄기가 내려와 바닥에 창살 무늬를 비춥니다. 그 위에 천장 곳곳에 길이·크기를 달리해 매달린 도트 철제 신호 랜턴 8개(`js/lanterns.js`: 사슬 고리, 크로켓 달린 뾰족 지붕과 처마, 납선 마름모가 든 첨두 유리창 3면, 늘어진 끝장식; 진자처럼 흔들리고 평소엔 작은 불씨만, 승인이면 초록 랜턴이 켜지고 거절이면 빨강 랜턴이 깜빡임), 뾰족 아치 심사 창구, 아치형 화면과 상태 표시등이 달린 확인 장치, 양피지 신청서와 밀랍 봉인(허가 초록·불가 빨강), 결과 배너가 있습니다. 심사관 외형은 시안입니다. |
| 소리 | 외부 파일 없이 WebAudio로 합성한 효과음입니다. 우측 상단 ♪ 버튼으로 끌 수 있습니다. |

## 테스트 가정 (공식 설정 아님)

- 판정은 `js/rules.js`(기존 테스트와 동일)의 기본 행마법만 확인합니다. 폰은 화면 위쪽으로 한 칸입니다.
- NFC와 이미지 인식은 시뮬레이션입니다. 카메라 모드는 실제 영상을 띄울 수만 있습니다.
- 지형, 지역 이름(네온 지구·성곽 도시 등), 심사관 외형, 색은 모두 시안이며 이동 가능 여부와 무관합니다.
- 주민 74명은 고정된 테스트용 배치입니다. 한 구역에 여러 말이 있을 수 있습니다.
