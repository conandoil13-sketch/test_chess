# 이동 흐름 테스트

이 디렉터리에서 `python3 -m http.server 8000`을 실행하고 브라우저에서 http://localhost:8000 을 엽니다.

캐릭터를 클릭하고 임의의 목적지를 선택한 후 임시 검사를 실행합니다. 승인은 위치를 변경하고 거절은 위치를 유지합니다. 검사 전 취소하거나 Esc를 눌러 닫을 수 있습니다.

테스트 가정: 20×20 평면, 장애물 없음, 폰은 위쪽 한 칸, 킹을 포함한 나머지 계급은 기본 행마법을 따릅니다. 원거리 이동의 거리 제한, 통행증, 지형, 면 사이 이동, 턴 완료 조건은 구현하지 않았습니다. 이 가정은 공식 설정이 아닙니다. NFC와 이미지 분류는 구현하지 않았습니다.

시각 실험: 구역별 도시·마을·들판·강을 임시로 배치하고, 각 구역을 4×4 부지로 나눠 건물 유무와 종류를 결정합니다. 같은 좌표는 새로고침해도 같은 모습입니다. 지형과 건물은 이동 가능 여부에 영향을 주지 않습니다. 월드 배치와 중세·사이버펑크 표현은 공식 설정이 아닌 시안입니다.

## 건물 스프라이트 연결

`assets/buildings/sprites.js`의 `null`을 `./assets/buildings/파일이름.png`처럼 이미지 경로로 바꾸고 새로고침합니다. `medieval`, `cyber`, `tower`는 각각 256×256, `large`는 512×512 픽셀 이미지입니다. 빈 항목은 임시 건물을 유지하며 오류로 표시하지 않습니다. 등록한 이미지가 없거나 크기가 다르면 해당 건물에 빨간 느낌표와 패널 안내가 나타납니다. 투명 배경 PNG를 사용할 수 있습니다.

대형 건물은 테스트용 확률로 일부 지역에 생성되며, 한 구역의 4×4 부지 중 2×2를 차지합니다. 건물의 배치와 이동 규칙은 서로 독립적입니다.
